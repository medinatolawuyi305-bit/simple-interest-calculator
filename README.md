A simple-interest-calculator is a tool used to calculate the interest earned on money saved or the interest payable on money borrowed over a specific period.
it uses a simple mathematical formula
Formular used: The standard simple interest formula:
SI = P x R x T/100
Where SI = Simple Interest
P = Principal (original amount of money)
R = Interest rate per year (%)
T = Time (in year)
Input & Outputs: What data the user enters and what result the program outputs.
